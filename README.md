## Estructura

- index.html
    Página principal, búsqueda normal con Google

- images.html
    Página de búsqueda de images

- advance.html
    Página de búsqueda avanzada

- style.css
    Estilo para index.html y para images.html

- styleadvance.css
    Estilo para advance.html
